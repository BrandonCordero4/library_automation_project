Library Spreadsheet Processor

Upload a spreadsheet and select the range of rows to process. Your spreadsheet has to have a column called: "TITLE", where this program will draw the title and author from. If there is an author, it must be seperated from the title by a forward slash (/). It also must have a column called: "OL" where it will write in and color the result of the search. Please make sure your start row is equal to or less than your end row, and that any file you upload is a .xlsx file.
